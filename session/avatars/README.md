# The band's faces

One mark per player, 160×160 PNG with transparency, drawn for the session-01
videos so the band has something to look at instead of five names.

| file | player | part |
| --- | --- | --- |
| `sticks.png` | sticks | drums |
| `lowend.png` | lowend | bass |
| `clavinet.png` | clavinet | keys |
| `scratch.png` | scratch | guitar |
| `maestro.png` | maestro | bandleader — doesn't play |

They carry no meaning in the music pipeline: nothing in `band/` or `session/`
reads them. They're here so a video, a report or a slide deck can put a face on
each part. The shapes and colours are arbitrary but fixed — keep them consistent
if you cut new content from an old session.
